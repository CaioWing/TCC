This work addresses the low-level optimization of inference kernels applied to computer vision models, focusing on the Vision Transformer (ViT) architecture, motivated by the latency and energy constraints of onboard perception in Unmanned Aerial Vehicles (UAVs). The primary objective is to reduce the data transfer bottleneck between global memory and the GPU's Streaming Multiprocessors (SM), a phenomenon associated with the ``Memory Wall,'' which is particularly severe on the edge hardware carried by such vehicles. To this end, a fused attention kernel is developed using OpenAI Triton, exploring tiling, data reuse in registers and SRAM, and online softmax computation to avoid fully materializing the intermediate attention matrix. The validation compares the custom implementation against PyTorch baselines using latency, throughput, numerical error, memory traffic, and Roofline analysis. The results indicate that operator fusion substantially reduces global memory traffic and accelerates execution relative to the explicit implementation, although it remains below PyTorch's optimized backend. Based on the measured arithmetic intensities, the implications for UAV-class embedded platforms are discussed, showing that the lower memory bandwidth of edge devices makes operator fusion proportionally more advantageous. This work contributes an experimental implementation and an analysis protocol for investigating performance bottlenecks in attention kernels applied to Vision Transformers.
