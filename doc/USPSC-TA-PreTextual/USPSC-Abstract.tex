This work addresses the low-level optimization of inference kernels applied to computer vision models, with a specific focus on the Vision Transformer (ViT) architecture. The primary objective is to reduce the data transfer bottleneck between High Bandwidth Memory (HBM) and the GPU's Streaming Multiprocessors (SM), a phenomenon associated with the ``Memory Wall.'' The methodology is based on the development of a fused attention kernel using OpenAI Triton, exploring tiling strategies, data reuse in registers and SRAM, and online softmax computation to avoid fully materializing the intermediate attention matrix. The proposed validation compares the custom implementation against PyTorch baselines using latency, throughput, numerical error, memory traffic, and Roofline analysis. The goal is to evaluate to what extent operator fusion and awareness of the memory hierarchy can bring attention execution closer to the effective hardware limits. This work contributes an experimental implementation and an analysis protocol for investigating performance bottlenecks in attention kernels applied to Vision Transformers.
