This work addresses the low-level optimization of inference kernels applied to computer vision models, focusing on the Vision Transformer (ViT) architecture. The primary objective is to reduce the data transfer bottleneck between High Bandwidth Memory (HBM) and the GPU's Streaming Multiprocessors (SM), a phenomenon associated with the ``Memory Wall.'' To this end, a fused attention kernel is developed using OpenAI Triton, exploring tiling, data reuse in registers and SRAM, and online softmax computation to avoid fully materializing the intermediate attention matrix. The validation compares the custom implementation against PyTorch baselines using latency, throughput, numerical error, memory traffic, and Roofline analysis. The results indicate that operator fusion substantially reduces global memory traffic and accelerates execution relative to the explicit implementation, although it remains below PyTorch's optimized backend. This work contributes an experimental implementation and an analysis protocol for investigating performance bottlenecks in attention kernels applied to Vision Transformers.
